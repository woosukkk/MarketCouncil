# 로그인 시 일일 분석 확인과 공식 게시

설정: 프로젝트 Python으로 `python -m desktop.daily_official --setup`을 실행합니다. 공식 운영자 이메일의 새 로그인 링크를 입력하고 저장합니다. OpenAI 키와 DART 키 및 갱신 토큰은 현재 Windows 계정 DPAPI로 암호화해 LocalAppData/MarketCouncil/daily/credentials.dpapi에 보관합니다. 저장소와 배포에 포함하지 않습니다. 같은 Windows 계정 권한을 가진 프로그램은 복호화할 수 있으므로 PC 계정 보안이 필요합니다.

저장 후 Windows 작업 스케줄러의 MarketCouncil Daily Samsung Official 작업을 등록하고 실행 이력 창을 엽니다. 이후 Windows 로그인 30초 뒤에 창을 표시하며, 오전 9시 자동 실행은 하지 않습니다. 창에는 한국 시간 기준 날짜·기업·실행 상태를 표시하고, 오늘 실행 또는 지금은 안 함을 선택할 수 있습니다. 실행 버튼을 누르기 전에는 계정 갱신, 근거 수집, Docker 시작, 유료 분석, 공개 게시를 하지 않습니다. 사용자 로그인이 필요하며 PC가 꺼져 있으면 실행하지 않고 절전에서 깨우지 않습니다. 오늘 공식 결과가 있거나 다른 작업이 실행 중이면 실행 버튼을 비활성화합니다.

날짜별 최종 상태는 LocalAppData/MarketCouncil/daily/history에 저장하며 API 키·원문·결과 경로를 포함하지 않습니다. 오류는 기존 errors와 last-error 메타데이터를 이용해 실패 단계·예외 종류·허용된 API/HTTP/네트워크 코드를 보여줍니다. 원인 코드가 없는 오류는 정확한 원인을 확인할 수 없다고 표시합니다. 과거 체크포인트만 있는 날짜는 게시 여부 미확인으로 표시하며, 과거 날짜를 선택해도 실행은 오늘 날짜에만 적용됩니다. 이후 게시에 성공한 날은 이전 오류와 최종 성공을 구분합니다.

창을 닫으면 새 분석을 시작하지 않습니다. 실행을 누른 뒤 창을 닫으면 이미 시작한 작업은 계속됩니다. 데스크톱의 준비 상태 → 운영자 · 실행 이력 / 오늘 실행에서 다시 열 수 있습니다. 소스 실행은 `python -m desktop.daily_official --prompt`, 패키지 진입점은 `--daily-prompt`입니다. 기존 `python -m desktop.daily_official` 및 `--daily-official`은 명시적인 직접 실행용으로 유지합니다. 기존 예약 작업은 갱신된 설치 스크립트로 다시 등록해야 오전 9시 트리거가 제거됩니다.

분석이 중단되면 같은 날 완료 단계를 재사용해 최대 한 번 복구합니다. 최초 분석을 포함한 당일 분석 시도는 최대 2회이며, 이미 게시된 날은 추가 분석하지 않습니다. 업로드만 실패한 경우 저장된 JSON을 다음 실행에서 재게시합니다. 분석 결과와 인용은 공식 공개되며 과거 날짜의 실패 결과는 자동 공식 게시하지 않습니다.

완료·실패 알림은 표시 후 8초 뒤 자동으로 닫힙니다. 분석은 콘솔 없는 Python으로 동작합니다. 실행 이력 창은 자동으로 닫지 않으며, 창을 닫으면 실행용 PowerShell도 종료됩니다. 기존 터미널 전체를 강제로 종료하지 않습니다.

자동 실행이 직접 시작한 검색 컨테이너는 분석·게시가 끝나거나 실패하면 정지합니다. 직접 시작한 Docker Desktop도 다른 컨테이너가 실행 중이지 않을 때 정상 종료합니다. 실행 전부터 사용 중이던 Docker·검색 서버와 외부에서 관리하는 서비스는 유지하며, 상태를 확인할 수 없을 때도 강제 종료하지 않습니다. 컨테이너·볼륨·분석 결과는 삭제하지 않습니다. Docker 정리는 알림 전에 수행하며, 다음 분석 시 필요한 서비스를 다시 시작합니다.

정리 실패는 게시 성공을 실패로 바꾸지 않습니다. 비밀정보 없는 로컬 오류 기록에 cleanup_search·cleanup_docker 단계를 남겨 종료 문제를 게시 실패와 구분합니다.

중지: 작업 스케줄러에서 해당 작업을 사용 안 함으로 설정합니다. 인증 실패 시 설정을 다시 실행해 연결합니다. 원문과 결과는 자동 삭제하지 않습니다. 이력 창은 이번 변경 이후 소스와 다음 패키지 빌드에 포함되며, 이미 배포된 desktop 0.8.1 실행 파일은 갱신되지 않습니다. 새 프로그램의 준비 상태 탭에서 자동 게시 설정을 열 수 있습니다. 실행 파일을 옮기면 설정을 다시 저장해 예약 경로를 갱신하세요. 동일 PC 동시 실행은 파일 잠금과 스케줄러 IgnoreNew로 제한합니다. 다른 운영자의 동시 공식 지정은 기존 RPC 정책을 따릅니다.
