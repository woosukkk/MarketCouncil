# 매일 삼성전자 자동 공식 게시

설정: 프로젝트 Python으로 `python -m desktop.daily_official --setup`을 실행합니다. 공식 운영자 이메일의 새 로그인 링크를 입력하고 저장합니다. OpenAI 키와 DART 키 및 갱신 토큰은 현재 Windows 계정 DPAPI로 암호화해 LocalAppData/MarketCouncil/daily/credentials.dpapi에 보관합니다. 저장소와 배포에 포함하지 않습니다. 같은 Windows 계정 권한을 가진 프로그램은 복호화할 수 있으므로 PC 계정 보안이 필요합니다.

저장 후 Windows 작업 스케줄러의 MarketCouncil Daily Samsung Official 작업을 등록하며 첫 확인을 시작합니다. 로그인 2분 후 및 매일 오전 9시 PC 현지 시간에 실행합니다. 한국 시간 기준 날짜별로 한 번 분석하며 현재 PC 시간대가 한국인지 확인해야 합니다. 사용자 로그인이 필요하며 PC가 꺼져 있으면 실행하지 않습니다. 절전에서 깨우지 않습니다. 오늘 공식 결과가 있으면 분석 없이 종료합니다.

분석 실패와 중단은 같은 날 자동 재분석하지 않아 중복 비용을 제한합니다. 업로드만 실패한 경우 저장된 JSON을 다음 실행에서 재게시합니다. 완료·실패는 Windows 알림 창으로 표시하며 분석 결과와 인용은 공식 공개됩니다. 당일 재시도 알림은 로그인마다 표시될 수 있습니다. 과거 날짜의 실패 결과는 자동 공식 게시하지 않습니다.

중지: 작업 스케줄러에서 해당 작업을 사용 안 함으로 설정합니다. 인증 실패 시 설정을 다시 실행해 연결합니다. 원문과 결과는 자동 삭제하지 않습니다. 현재 소스 실행용이며 기존 desktop 0.4.0 바이너리에는 포함되지 않습니다. 동일 PC 동시 실행은 파일 잠금과 스케줄러 IgnoreNew로 제한합니다. 다른 운영자의 동시 공식 지정은 기존 RPC 정책을 따릅니다.
