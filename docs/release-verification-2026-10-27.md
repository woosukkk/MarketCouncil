Windows 패키지는 기업 조회·결과 형식 검증·네트워크 오류 수정, 로컬 실행 시간 기록과 운영자 자동 게시 설정을 포함한다. 예약 실행은 EXE 진입점을 사용하며 키·갱신 토큰은 명시적 설정 저장 때만 현재 Windows 계정에 암호화한다. 기존 PC의 소스 예약 작업은 이번 배포에서 재등록하지 않았다. 웹에는 새 다운로드·성능 기록 안내와 기존 미배포 결과 검증·게시 후 목록 갱신 코드를 반영했다.

## 검증

- 소스 관련 unittest 78개와 웹 검사 37개 통과. 깨끗한 소스 스냅샷 검사에서는 소스 전용 venv 존재 조건과 PowerShell 모의 출력 인코딩만 테스트 환경에서 보완했다. 제품 소스는 수정하지 않았다.
- Windows 프로그램 초기화: 별도 프로필에서 GUI·복구 워크플로·브라우저 드라이버·Crawl4AI 리소스 초기화, 종료 코드 0. 실제 분석은 호출하지 않았다.
- ZIP을 풀어 실행한 일일 진입점: 가짜 암호화 자격증명과 완료된 날짜 상태를 별도 프로필에 만들고 분석·게시 없이 종료 코드 0을 확인했다. 실제 계정·키·예약 작업은 사용하지 않았다.
- ZIP 파일 9,815개를 확인하고 필수 모듈·빌드 메타데이터·설치 스크립트 포함, 개인 환경 파일·인증 파일·분석 결과·모델 캐시 제외를 확인했다.
- ZIP 462,807,944 bytes. SHA-256: 36a2bd9468552aaa2cd3607e83b6d8e4838790aa62b11cd379c717ca9cca9aa2. GitHub 자산 digest 및 공개 SHA256.txt 내용과 일치했다.
- 공개 ZIP HEAD 응답 200과 정확한 길이를 확인했다. 본문을 다시 내려받지는 않았다.
- 운영 /, /app, /download 각각 GET 응답 200. 실제 JS index-DJqLUdmw.js에서 0.5.0 ZIP 링크·자동 게시 설정·metrics 안내를 확인했고 이전 0.4.0 ZIP 링크가 제거됐다. 공개 Supabase 프로젝트 연결 값도 포함됐다.

## 남은 검증

새 유료 분석·실제 EXE 예약 등록·별도 깨끗한 PC의 전체 분석은 실행하지 않았다. 소스 자동 실행의 기존 실제 검증과 새 패키지의 초기화 검증을 구분해야 한다. 이번 브라우저 자동 조작은 도구 시간 초과로 화면 검증을 완료하지 못했으며, 공개 HTTP 및 실제 배포 번들 검증은 통과했다. 다운로드·운영자 설정 화면의 수동 확인과 새 PC 검증은 후속으로 남긴다. API 키·토큰·원문·계정·운영 DB 권한은 이 배포에서 변경하지 않았다.
