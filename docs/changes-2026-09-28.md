# 2026-09-28 MarketCouncil 변경 기록

기준: 한국 시간 2026-09-28. 웹 UI 개선, 기사형 요약, 내부 토론 품질 개선.

## 웹 화면과 정보 배치

- 토론 보기와 새 분석을 별도 화면으로 분리했다. 분석 실행 폼이 토론 상단을 차지하지 않는다.
- 결론과 주요 토론 본문을 크게 배치하고, 보조 정보와 근거 영역은 상대적으로 좁혔다.
- 카드 배경과 대비를 강화했다. 파랑·남색은 선택/강조, 민트는 상승 관점, 장미색은 하락 관점, 호박색은 추가 확인에 사용한다.
- 상승·하락 관점의 비중은 동일하게 유지한다.
- 관련 파일: `streamlit_app.py`, `app/debate_ui.css`, `.streamlit/config.toml`.
- 디자인 참고 및 적용 이유: `docs/debate-web-design.md`.

## 기사형 요약

- 기존 중재자가 기사 제목, 도입 설명, 쟁점 중요도 순서를 생성한다. 별도 에이전트나 추가 호출은 도입하지 않았다.
- 중요한 쟁점을 맨 위에 배치하고, 기사 선택 시 해당 쟁점의 토론 상세를 보여준다.
- 중요도는 투자 가설 영향, 반대 근거 강도, 추가 확인 시급성을 기준으로 정한다.
- 과거 결과에 기사 필드가 없으면 기존 의제 제목과 요약으로 표시한다. 저장된 결과를 자동 재분석하지 않는다.
- 관련 파일: `agents/moderator_agent.py`, `agents/moderator_prompt.py`, `app/debate_view_data.py`, `streamlit_app.py`.

## 내부 토론 품질 개선

### 발언 직후 인용 확인

- 각 발언의 source_id와 quote_id 쌍을 제공된 근거 카탈로그와 대조한다.
- 유효한 인용에는 카탈로그의 원문을 붙인다. 잘못된 인용은 evidence에서 제외하고 citation_errors에 남긴다.
- 다음 발언자와 중재자는 검증 결과를 함께 받는다.
- 이 검사는 인용의 존재 확인이다. 인용이 주장을 실제로 뒷받침하는지는 중재자가 별도로 평가한다.

### 최종 요약에 원본 데이터 전달

- 최종 요약 단계에 금융 데이터와 근거 카탈로그를 전달한다.
- 양측이 동의했다는 이유만으로 미검증 주장을 사실로 취급하지 않도록 지시했다.

### 반복 판정 개선

- 인용 이유나 주장 문구가 달라졌다는 이유로 새 정보로 계산하지 않는다.
- 전체 이전 라운드와 비교하여 새로 등장한 유효 인용을 판정한다.
- 같은 근거를 사용하더라도 실제 가설 수정·철회·새로운 인정이나 근거 있는 추론이 생겼다면 중재자가 변화와 이유를 기록할 수 있다.
- 최소 2회·최대 3회와 기존 발언 순서는 유지한다. 발언 순서 교대와 최소 라운드 변경은 이번 적용 범위가 아니다.
- 수정 파일: `agents/analysis_debate_agent.py`, `agents/moderator_agent.py`, `agents/moderator_prompt.py`, `tests/test_debate_termination.py`.

## 검증과 한계

- 토론 단위 테스트 10개 통과: 인용 쌍 불일치, 원문 복원, 잘못된 인용 제외, 표현만 바뀐 반복, 과거 인용 재사용, 실질적 변화, 원본 데이터 전달, 라운드 제한.
- Streamlit AppTest 4개 통과: 기사 우선순위와 이동, 실행 상태, 근거 선택, 빈 결과 화면.
- 실제 유료 LLM 호출은 수행하지 않았다. 의미 판단의 품질과 실제 생성 결과는 다음 새 분석에서 확인해야 한다.
- 새 토론 로직은 다음 분석 실행부터 적용된다. 이미 실행 중인 분석이나 기존 저장 결과를 소급 변경하지 않는다.
