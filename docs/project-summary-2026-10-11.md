# MarketCouncil 개발 핵심 보고서

작성자 이우석  |  2026년 10월 11일  |  구현 및 검증 기록 기준 2026년 10월 10일

## 1 목적과 구성

MarketCouncil은 기업 자료를 근거로 상승과 하락 관점의 AI가 가설을 검토하는 투자 리서치 시스템이다. 결론뿐 아니라 해석이 갈리는 지점과 반대 근거, 미확인 사항을 보여주는 데 목적이 있다.

Python과 LangGraph가 수집 및 토론을 관리하고 OpenAI 모델이 분석과 중재를 수행한다. BAAI/bge-m3와 ChromaDB가 문서 검색을, React와 Vercel이 웹 화면을, Supabase가 인증과 결과 저장을 담당한다. 분석은 사용자 PC에서 실행하고 게시 결과는 웹에서 열람한다.

기업명 확인 → 금융 및 공시 자료 수집 → 근거 검색 → 상승과 하락 분석 → 의제 선정과 반론 → 쟁점 정리 → 로컬 저장과 선택적 공개.

## 2 AI 토론과 새로운 관점

Bull은 상승 가설을, Bear는 하락 위험을 구성하며 Moderator가 의제를 최대 3개 선정한다. 발언과 반론, 중재 검토를 2~3라운드 진행하고 새 유효 근거나 실질적 변화 없이 반복하면 종료한다. 합의점과 미해결 쟁점, 필요한 추가 증거를 남긴다.

예를 들어 투자 지출은 성장 준비이면서 현금흐름 부담일 수 있다. 토론은 같은 사실의 대안적 해석과 반증 조건을 드러낸다. 같은 모델에 역할을 나눈 구성이므로 독립 전문가의 합의는 아니며 공통 편향과 발언 순서의 영향이 남는다.

## 3 RAG와 환각 완화

RAG는 관련 문서를 검색해 모델 입력에 제공한다. 기업명과 기준일 필터로 다른 기업 및 미래 자료 혼입을 제한하고, 유사도와 최신성 규칙으로 순위를 조정한다. 근거에 출처와 인용 식별자를 부여해 토론과 원문을 연결한다.

제공된 카탈로그에 없는 인용은 유효 근거에서 제외하고, 유효 인용은 저장된 원문으로 복원한다. 사실과 가설 구분, 확인 불가 표시, 반대 관점 및 반복 종료를 적용했다. 다만 인용의 존재는 주장의 사실성을 보증하지 않는다. 검색 누락과 선택적 인용도 남으며 환각 감소율은 아직 측정하지 않았다.


## 4 구현 성과와 서비스 구조

이메일 및 GitHub 로그인, 관심기업, 분석 북마크, 개인 결과 가져오기와 공유 기능을 구현했다. 개인 토론은 기본 비공개이며 선택한 결과만 공유하거나 공개한다. 운영자는 날짜별 공식 토론을 지정한다. PDF와 임베딩은 로컬에 두고 클라우드에는 결과와 필요한 인용만 저장한다.

삼성전자 실제 분석 1회에서 2라운드 결과를 생성하고 비공개 저장 후 공식 공개와 비로그인 열람을 확인했다. 관리자 성능 기록 저장 및 재조회도 검증했다. 최근 관련 테스트 20개와 웹 빌드가 통과했다. Lighthouse 모바일 실험실 측정 1회의 웹 성능은 63점이었다. 이는 이전 웹 버전의 단일 측정으로 실제 방문자 평균이나 AI 정확도를 뜻하지 않는다.

## 5 개선 가능한 사항

첫째 정답 기반 평가를 우선한다. 사람이 검토한 질문과 근거로 검색 Recall, Precision, MRR과 지연을 측정하고 단일 답변, RAG 답변, 토론을 같은 조건에서 비교한다. 사실 오류와 유용한 반대 논거도 평가한다. 현재 평가 도구는 구현했지만 실제 RAG 점수는 미측정이다.

둘째 검색과 인용 품질을 높인다. 문단 및 표를 보존하는 청킹, 키워드와 벡터 검색 결합, 재순위를 후보로 검토한다. 날짜 누락과 중복 출처를 정리하고 인용이 실제 주장을 지지하는지 검증한다. 개선 효과는 고정 데이터로 비교한 뒤 채택한다.

셋째 편향과 외부 입력 위험을 점검한다. 발언 순서 변경과 독립적인 최초 분석으로 순서 효과를 비교하고, 외부 문서의 악성 지시 방어를 강화한다. 다른 모델 활용은 비용과 지연을 함께 평가한다.

넷째 사용자 환경과 운영 측정을 개선한다. 새 PC 설치와 분석부터 게시까지 전체 흐름을 검증하고 다음 패키지에 성능 수집기를 반영한다. 단계별 시간과 토큰·비용을 기록하며 웹 초기 표시, 메일 발송 및 저장량을 점검한다. 기존 PC 0.4.0에는 새 수집기가 없다.

## 6 결론

근거 수집과 AI 토론을 사용자 결과 보관 및 공개까지 연결한 프로토타입이다. 핵심 가치는 반대 논거와 불확실성을 검토 가능하게 만든 데 있다. 다음 과제는 실제 정답 기반 평가와 인용 의미 검증을 통해 환각 완화와 관점의 유용성을 확인하는 것이다.
