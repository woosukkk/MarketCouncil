# Windows 0.7.0 · 웹 0.13.1 다기업 배포 검증

검증일: 2026-11-03. 관련 이슈: https://github.com/woosukkk/MarketCouncil/issues/28

## 변경과 원인

개인 분석의 우선 대상을 SK하이닉스·현대차·NAVER·Apple·Microsoft로 확장했다. 공통 기업 식별과 실행 시 기업명/티커 연결을 적용했다. 실제 조회에서 현대차가 현대차증권으로 잘못 매칭되는 원인을 확인해 알려진 국내 이름은 종목코드로 먼저 상장 목록을 대조한다. 후보가 모호하면 사용자가 선택한다.

삼성전자 공식 일일 자동 게시는 유지한다. 운영 DB/계정 권한이나 기존 결과·자동 게시 설정은 변경하지 않았다. [다기업 지원 범위와 공개 공급자 확인](multi-company-verification-2026-11-03.md)을 함께 참고한다.

## 소스와 자동 검사

- 실제 빌드 커밋: `8a15dcd8e1d26d91ec9bfd1ac303dc4bc9836c38`. 기존 미커밋 작업과 비밀 파일을 포함하지 않은 git archive 스냅샷이다.
- 해당 스냅샷에서 Python **126개**, 웹 **57개** 검사와 Vite 프로덕션 빌드 통과. 반복 실행 수를 합산하지 않았다.
- 실제 공개 기업 검색·재무 수집에서 다섯 종목, KRW/USD 통화 구분, 가격·시가총액 및 각 연간 매출 4기간 공급을 확인했다. 모델/계정 업로드/공식 게시 호출은 실행하지 않았다.
- 같은 Desktop 인스턴스의 모의 분석→실제 임시 JSON 저장→모의 비공개 업로드를 검증했다. 테스트 중 모듈 정체성 복원과 한글 설치 경로의 PowerShell JSON 출력 인코딩 문제를 수정해 결합 검사를 통과시켰다.
- 다운로드 안내 번역 항목의 구문 누락은 배포 전 검사에서 발견해 수정했다. 오류가 남은 스냅샷은 공개 배포하지 않았다.

## 실제 패키지 확인

- Windows ZIP: **462,820,880 bytes**, **9,816개 항목**. CRC·필수 동적 리소스·단가 JSON·실제 빌드 메타데이터 일치를 확인했다.
- SHA-256: `dea02845cf27c0f0779783c7f6da47993cb843da5c41f7130ecccb2123386c8f`. GitHub 자산 digest와 공개 체크섬이 일치하고 공개 ZIP HEAD/체크섬 GET은 200이었다. 공개 ZIP 전체를 다시 내려받지는 않았다.
- 원문 문서·결과·Chroma DB·모델 가중치·사용자 설정·인증 파일이 ZIP에 포함되지 않았음을 확인했다.
- 압축을 푼 실제 EXE를 별도 프로필에서 `--self-check`로 실행해 종료 코드 **0**, GUI/워크플로·브라우저 리소스·다기업 프리셋·합성 단계/토큰/단가 계측 검사를 통과했다. 이 초기화 검사는 실제 AI 토론 품질이나 별도 PC 전체 실행 검증이 아니다.

- 운영 다운로드: https://frontend-six-pi-h5i7tztups.vercel.app/download
- Vercel: `dpl_C3biXzbTdHE1obQDJE4P4MBB9aFG`, READY. `--skip-domain`으로 먼저 준비하고 Windows 공개 검증 후 기존 운영 별칭을 전환했다.
- 공개 소개·리서치·다운로드 경로와 실제 `/assets/index-McQb-mU9.js` 번들에서 새 ZIP 링크·영문 다기업 안내·언어 전환을 확인했다. 실제 브라우저에서도 한영 다운로드 안내와 0.7.0 링크를 확인했다.

새 ZIP을 별도 폴더에 풀고 `_internal`을 유지한다. 자동 게시를 이용하면 새 폴더에서 설정을 다시 저장해 예약 경로를 갱신한다. 기존 결과·계정 설정과 예약 작업을 자동으로 바꾸지 않는다.
