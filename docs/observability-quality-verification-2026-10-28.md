# 단계별 관측과 답변 근거 평가 검증

검증일: 2026-10-28. 관련 이슈: https://github.com/woosukkk/MarketCouncil/issues/24

## 구현과 원인

기존 수집기는 분석 전체 시간만 저장했고 토론의 일부 구조화 응답만 개별 진단 파일에 남겼다. 직접 호출하는 다른 Responses 경로와 병렬 작업의 실행 문맥이 빠져 전체·단계별 사용량을 함께 비교할 수 없었다. 모든 Responses 호출을 공통 계측으로 연결하고, 병렬 Bull/Bear와 LangGraph 단계·체크포인트 재사용을 같은 실행에 묶었다.

관측 입력·캐시 입력·출력·추론 토큰과 API 단계별 시간·요청·오류·토큰 추정 비용을 집계한다. 사용량이 없는 실패를 0원으로 만들지 않고, 재사용 단계의 과거 토큰을 새 호출에 합산하지 않는다. 관측 토큰만의 추정이며 SDK 내부 재시도·도구 요금·계정 청구서는 포함하지 않는다. 겹치는 단계 시간을 더해 전체 시간으로 표시하지 않는다.

답변 근거 평가는 실제/합성 사례, 사람/모델/미검토 출처를 구분한다. 로컬 검토 큐와 별도 예측을 ID·입력 해시로 대조하고 사람 정답과 비교한 사례만 판정 일치율을 계산한다. 인용 ID·수치 일치가 주장의 의미 지지나 사실성을 보증하지 않는다. 관리자 보고에는 원문·주장·URL·키·원본 오류가 없으며 고정 라벨·수치·해시만 남긴다.

RAG 미래 자료 집계가 호스트 시간대에 의존하던 별도 결함도 검색기와 같은 KST 말일로 맞췄다. 기존 KST 실행 점수가 틀렸다고 확정하거나 검색 순위가 개선됐다고 주장하지 않는다.

## 검증 결과

- 통합 Python 132개 통과. 모의 API, 예외·재시도 보존, 병렬 실행 분리, 실제 LangGraph 노드·실제 workflow executor의 문맥 전달, 캐시 재사용, 누락 사용량, 단가 오류, 민감 필드 제외를 포함했다.
- 깨끗한 커밋 스냅샷의 핵심 Python 71개와 웹 48개를 재검증해 통과했다. 중복된 검사이므로 통합 검사 수에 다시 더하지 않는다. 기본 sandbox의 임시 파일 원자적 교체 권한 오류는 승인된 정상 권한에서 소스 수정 없이 해소됐다.
- 실제 Python 모의 부분 사용량 보고서와 원문 없는 실제 품질 보고서를 JS 파서로 읽어 계약 일치를 확인했다. 사용량 확인 0회인데 양수 비용을 넣거나 단가·모델·완전 추정 산식을 어긋나게 만든 보고서는 거부한다.
- 웹 프로덕션 빌드 성공. /, /app?view=admin, /download GET 각각 200. 실제 index-BRrqQEMN.js에서 answer_quality, by_phase, usage_missing_calls와 새 품질 탭·기존 0.5.0 다운로드 링크를 확인했다. 로그인·DB 조회·파일 업로드는 수행하지 않았다.

## 저장 결과의 실제 오프라인 점검

2026-10-27 저장된 삼성전자 토론을 로컬로 읽었다. 쟁점 12개 중 수치 재검토 대상은 7개, 보존된 인용 연결 불충족과 미래 자료는 각각 0개였다. 이는 최종 저장 인용을 다시 검사한 결과이며 생성 중 제거된 모든 인용 시도 횟수를 뜻하지 않는다. 사람 검수·별도 예측 비교는 0개라 의미 판정 일치율은 null/미평가다. 7/12를 오답률이나 할루시네이션 비율로 제시하지 않는다.

로컬 검토 큐: results/verification/quality-review-20261027.json. 관리자 가져오기용 안전 보고서: results/metrics/answer-quality-20261028.json. 두 파일은 Git 제외이며 자동 원격 업로드하지 않았다. 사람 출처와 해시는 원본 진위·독립 전문가 검수를 인증하지 않는다.

## 적용 범위와 제한

웹은 web-v0.12.0으로 배포했다. 실제 빌드 커밋은 0918b6e8255c9ce44e8f8682e7ab949e8ca87432이고 배포 주소는 https://frontend-5akd9zjnw-woosukk.vercel.app 이다. 기존 미커밋 작업은 커밋과 배포에서 제외했다.

상세 계측은 업데이트한 로컬 소스의 다음 분석부터 생성된다. 예전 기록을 소급 보충하지 않으며 현재 다운로드 0.5.0에는 상세 수집이 없다. 이번에 새 Windows 바이너리·실제 유료 분석·실제 계정 업로드·운영 DB 변경·공식 게시를 실행하지 않았다.

실제 RAG 모델 재측정은 시작 직전 가용 메모리 2,686MB가 3GiB 조건을 충족하지 않아 모델을 로드하지 않았다. 새 검색 점수나 전체 분석 성능 개선율은 없다. 다음 실제 소스 실행의 관측과 사람 정답 검수가 후속 검증이다.
