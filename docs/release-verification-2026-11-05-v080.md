# Windows 0.8.0 · 웹 0.14.0 다기업 근거 준비 배포

배포일: 2026-11-05 KST. 관련 이슈: https://github.com/woosukkk/MarketCouncil/issues/29

## 적용한 동작

- 웹 리서치 라이브러리에 6기업 선택, 실제 공개 기록 수, 결과가 없는 기업의 안내와 PC 분석 연결을 적용했다. 한영 인터페이스를 제공한다. 새 기업의 토론을 임의 생성하거나 공개하지 않았다.
- 관리자에 기업별 근거 현황·원문 출처/시점·자료 부족 이유와 보고서 가져오기를 추가했다. 기존 관리자 권한과 저장소에 메타데이터 보고서 1건을 보관했고, 운영 화면에서 4/6 및 기업별 보완 사항을 확인했다. DB 스키마/RLS는 변경하지 않았다.
- PC는 기업별 DART/SEC 공시와 공식 IR 본문을 준비하고, 원문·본문 해시와 기업/기간을 검사한 뒤 분석한다. 같은 URL의 갱신 원문이 이전 버전과 섞이지 않도록 했다.
- 최신 필수 원문의 추출·기간·기업 검증 실패가 과거 raw 캐시로 숨겨지지 않게 요청 ID를 추적한다. 완료된 분석 캐시는 기업/ticker/corpus별로 분리한다.
- 공식 자동 게시에서 준비된 6기업 중 새 공시 우선·순환 선택을 제공한다. 기존 저장 설정은 삼성전자 고정이며 새 모드는 직접 저장해야 적용된다. 이번 배포에서 예약 작업·자격증명 설정을 바꾸지 않았다.
- 실제 Microsoft 본문의 CRLF가 Windows 저장 중 CRCRLF가 되어 해시 불일치가 발생한 원인을 확인했다. 공통 추출 결과를 LF로 정규화해 실적 본문 2건의 정상 저장을 확인했다.

## 현재 자료 준비 상태와 보류한 검사

국내 4기업은 실제 파일 재검사에서 최소 자료 조건을 충족했다. Apple/Microsoft 실적 IR 본문은 확보했으나 SEC 요청 HTTP 403으로 연간/최근 공시가 부족하며, 이 조건에서는 분석을 차단한다. 이는 AI 정확도나 검색 품질 통과를 뜻하지 않는다.

사용자 요청에 따라 이번에는 전체 Python/웹 회귀 테스트와 유료 전체 분석·기업별 의미 품질 검증을 보류했다. 이전 회귀 결과를 최종 배포 소스의 통과 결과로 재사용하지 않는다. 기존 테스트용 preflight 모듈에 새 prepared_corpus를 반영하는 보완, SEC 접근 해결, 실제 6기업 토론 품질과 별도 PC 전체 실행은 후속 작업으로 남아 있다. 기간별 병합은 구현하지 않았다.
