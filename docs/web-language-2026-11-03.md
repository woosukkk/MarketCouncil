# 웹 한영 전환 검증 · 2026-11-03

관련 이슈: [#27](https://github.com/woosukkk/MarketCouncil/issues/27)

## 구현 범위

- 소개·리서치·다운로드 화면 오른쪽 위에 `한국어 / EN` 버튼을 추가했다. 로그인·개인 목록·토론·관리자 화면도 같은 언어 설정을 사용한다.
- 467개 고정 UI 문구를 영어 사전으로 분리했다. 기본 언어는 한국어이며, 지원되는 URL `lang` 값이 저장된 선호 언어보다 우선한다. 브라우저 저장소가 차단돼도 전환할 수 있다.
- 선택은 브라우저에 기억된다. 내부 이동·새로고침에서도 유지하며, 전환 시 기존 쿼리·공유 식별자·해시와 현재 토론·선택한 라운드를 보존한다.
- 저장 분석·기업명·인용문·출처 제목은 원문을 유지한다. 언어 전환으로 유료 번역·새 분석을 실행하지 않는다. Windows 프로그램과 기존 기술 문서는 이번 번역 범위가 아니다.
- GitHub에는 `README.en.md`와 양쪽 문서 오른쪽 위 언어 링크를 추가했다. 영문 소개 화면은 실제 운영 사이트를 캡처했다.

## 검증과 수정

- 최종 웹 테스트 55개 통과, Vite 프로덕션 빌드 성공. 사전의 매개변수 대응·고정 UI 문구 포함·알 수 없는 분석 텍스트의 원문 유지와 실제 React 컴포넌트의 영문 렌더링을 확인했다.
- 실제 컴포넌트의 Provider 없는 렌더링에서 기본 Context 번역 함수의 인자 순서 때문에 매개변수가 치환되지 않는 문제를 재현했다. 기본 함수를 한국어 번역 래퍼로 바꾸고 회귀 검증을 추가했다.
- 기존 인증·DB 작업 62개 호출의 인자를 AST로 비교해 동일함을 확인했다. OAuth 리디렉션과 DB 권한은 변경하지 않았다.
- 로컬 브라우저에서 공개 토론의 Round 2를 선택한 뒤 한영 전환해 선택 유지, 내부 이동·새로고침 후 선호 유지, 좁은 화면에서 리서치·다운로드 페이지의 수평 넘침 없음을 확인했다. 이는 실제 모바일 기기의 전체 검증을 뜻하지 않는다.
- 운영 브라우저에서 소개 페이지 전환, 실제 저장 분석 예시 로딩, 전환 후 리서치 이동과 기존 로그인 상태 유지를 확인했다. 새 이메일 전송·OAuth 로그인·개인 데이터 변경은 실행하지 않았다.
