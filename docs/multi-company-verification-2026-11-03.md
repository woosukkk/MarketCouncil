# 국내·미국 다기업 경로 검증 · 2026-11-03

관련 이슈: [#28](https://github.com/woosukkk/MarketCouncil/issues/28)

## 적용 범위

우선 대상은 SK하이닉스·현대차·NAVER·Apple·Microsoft다. 기존 PC 일반 분석의 기업 찾기와 후보 선택을 유지하고, 공유 식별기·구형 CLI/로컬 viewer의 선택 목록을 확장했다. 개인 분석 결과는 회사별로 로컬 저장하고, 사용자가 고른 결과만 기존 계정 권한으로 비공개 업로드한다. 삼성전자 공식 일일 자동 게시는 유지한다.

## 확인한 원인과 수정

1. 기존 금융 수집/구형 로컬 runner의 고정 지도는 3개 기업뿐이었다. `company_lookup`의 공통 프리셋·이름 정규화와 resolver를 사용한다. 그 외 이름은 정확히 일치하는 단일 후보 또는 유일 후보만 확정하며, 복수 후보는 PC에서 선택하도록 종료한다.
2. 실제 KIND 조회에서 `현대차`는 정식 상장명 `현대자동차`의 부분 문자열이 아니어서 `현대차증권 / 001500.KS`만 반환됐다. 알려진 국내 별칭·영문 표기는 종목코드로 상장 목록을 먼저 대조한다. 해당 종목이 없으면 다른 회사의 부분 일치로 대체하지 않는다. 수정 후 `현대차 → 현대자동차 / 005380.KS`를 실제 조회로 확인했다.
3. 실행 환경의 이전 티커가 다른 기업에 붙을 수 있었다. Desktop/일일 실행은 `MARKETCOUNCIL_COMPANY`와 `MARKETCOUNCIL_TICKER`를 함께 설정한다. 금융 수집은 기업 바인딩 불일치와 바인딩 없는 알려진 기업의 티커 불일치를 외부 재무 조회 전에 차단한다. 로컬 runner의 자식 환경도 선택 기업 값으로 덮어쓴다.
4. 명시적으로 고른 다른 거래소의 종목을 기본 프리셋으로 덮어쓰지 않는다. 기업명 없이 티커만 주는 기존 직접 호출은 미등록 기업에 한해 기존 동작을 유지하므로, 모든 회사의 티커가 독립 검증됐다고 해석하면 안 된다.

## 실제 공개 공급자 확인

OpenAI·모델·업로드 호출 없이 공개 KIND/Yahoo 기업 검색 및 Yahoo 재무 수집 경로를 실행했다. 다음 결과는 당시 공급 여부를 확인한 것이며 지속 제공이나 자료의 정확성을 보증하지 않는다.

| 입력 | 조회 후보의 정식 이름 | 종목 | 가격/재무 통화 | 연간 매출이 있는 기간 수 |
| --- | --- | --- | --- | --- |
| SK하이닉스 | SK하이닉스 | 000660.KS | KRW / KRW | 4 |
| 현대차 | 현대자동차 | 005380.KS | KRW / KRW | 4 |
| NAVER | NAVER | 035420.KS | KRW / KRW | 4 |
| Apple | Apple Inc. | AAPL | USD / USD | 4 |
| Microsoft | Microsoft Corporation | MSFT | USD / USD | 4 |

다섯 종목에서 가격·시가총액도 수집됐다. Apple·Microsoft 검색은 각각 복수 후보를 반환하므로 사용자가 이름·거래소·종목코드를 보고 선택한다. `현대차` 별칭 문제는 수정 전·후를 확인했고 다른 기업/예탁증서/해외 거래소 후보를 첫 결과만 보고 추정하지 않는다.

## 회귀 검증

- 기업 resolver·정확/유일/모호/누락 후보·잘못된 종목·이전 기업 바인딩·다른 거래소 명시 선택을 모의 공급자로 검사한다.
- 같은 Desktop 인스턴스에서 다섯 기업을 연속 선택해 모의 분석을 실행한다. 실제 임시 JSON 저장소와 실제 축약기를 사용해 기업명/티커/경로/업로드 ID 분리와 원문 제외·인용 유지·비공개 기본 유지를 확인한다. HTTP·모델·Docker는 모의 객체다.
- 테스트의 `sys.modules` 복원 중 새로 import한 모듈의 패키지 속성이 남아 다른 검사에 영향을 준 문제가 있었다. 실제 저장·렌더러 모듈을 먼저 읽고 원래 모듈 정체성을 확인해 전체 결합 실행을 통과시켰다.
- 웹은 같은 날짜의 다섯 결과를 병합해도 회사별 항목이 남고, 기업 필터·종목 검색·업로드 중복 방지가 분리되는지 검사한다.
- 기존 공식 운영자·삼성전자 제한, 일일 작업·복구·서비스 종료, 통화가 다른 가치 지표의 계산 차단도 관련 회귀 범위에 포함한다.

## 남은 품질 검증

새로운 다섯 기업의 실제 유료 전체 AI 토론은 실행하지 않았다. 검색/재무 제공과 모의 저장 검증은 RAG 검색 품질·주장 근거 적합성·예측 성능을 뜻하지 않는다. 실제 문서/정답 근거와 사람 검수, 기업별 평가셋을 마련해야 한다.

RAG는 현재 회사 메타데이터 정확 일치를 사용한다. 과거 문서의 `현대차/현대자동차`, `Apple/Apple Inc.` 등 별칭은 자동 통합하지 않으며, 해당 회사 문서가 없으면 다른 회사 자료로 채우지 않는다. 미국의 SEC 공시 수집 도구는 있지만 자동 역사 수집 경로가 국내 DART와 동등하게 연결됐다고 주장하지 않는다. 둘 다 후속 범위다.

운영 DB 권한·공개 상태·계정·기존 자동 게시 설정은 변경하지 않는다. 별도 PC의 설치부터 실제 분석까지 전체 검증도 남아 있다.
